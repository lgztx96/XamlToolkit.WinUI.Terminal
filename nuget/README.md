# XamlToolkit.WinUI.Terminal

Provides a **WinUI 3** version of the **TermControl** from [Windows Terminal](https://github.com/microsoft/terminal), enabling you to embed a terminal as a XAML control in WinUI 3 / Windows App SDK applications.

This version is based on the Windows Terminal source code around **v1.25.1171.0**. 

## Features

- Built on the official [microsoft/terminal](https://github.com/microsoft/terminal) project
- Native `TermControl` XAML control
- Supports x64, x86, and ARM64 architectures
- Available as a .NET managed wrapper and via C++/WinRT native references
